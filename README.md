# Sentinel AI

A full-stack mobile trading app for stocks and crypto, delivering real-time RSI-based signals, live market data feeds, and automated push-notification alerts. Built and shipped independently for iOS.

---

## What It Does

- Streams live market data for stocks and crypto assets
- Computes RSI (Relative Strength Index) signals in real time to surface trading opportunities
- Sends automated push notifications when signal thresholds are triggered
- Presents a clean, mobile-first interface for monitoring signals on the go

---

## Technical Highlights

- **Real-time signal logic** — RSI calculations computed against live market data feeds
- **Automated alerts** — push notifications triggered by signal thresholds, not manual refresh
- **Node.js backend** — handles data ingestion, indicator computation, and notification dispatch
- **React Native frontend** — cross-platform mobile UI optimized for fast, data-dense display
